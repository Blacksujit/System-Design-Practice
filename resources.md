| Book | Author | Focus |
|------|--------|-------|

| [System Design Interview - An Insider's Guide (Vol 1)](https://www.amazon.com/System-Design-Interview-insiders-Second/dp/B08CMF2CQF) | Alex Xu | ⭐ Best interview prep with 15 real problems |
| [System Design Interview (Vol 2)](https://www.amazon.com/System-Design-Interview-Insiders-Second/dp/B08CMF2CQF) | Alex Xu | Advanced problems like Kafka, Google Maps |
| [Designing Distributed Systems](https://www.amazon.com/Designing-Distributed-Systems-Patterns-Paradigms/dp/1491983647) | Brendan Burns | Kubernetes author's patterns |
| [Understanding Distributed Systems](https://understandingdistributed.systems/) | Roberto Vitillo | Free online book, practical |
| [Site Reliability Engineering](https://sre.google/sre-book/table-of-contents/) | Google | Production systems perspective |

## Key Concepts Checklist

### Must Know
- [ ] Scaling (vertical vs horizontal)
- [ ] Load balancing
- [ ] Caching (all strategies)
- [ ] Message queues
- [ ] SQL vs NoSQL
- [ ] Sharding/partitioning
- [ ] CAP theorem & PACELC
- [ ] Consistent hashing
- [ ] Rate limiting
- [ ] CDNs
- [ ] DNS
- [ ] API design (REST vs gRPC)

### Should Know
- [ ] Consensus (Raft, Paxos)
- [ ] Event sourcing & CQRS
- [ ] Two-phase commit
- [ ] Heartbeat & election
- [ ] Distributed caching
- [ ] Blue-green deployment
- [ ] Circuit breakers
- [ ] Idempotency
- [ ] Backpressure
- [ ] Chaos engineering

### Nice to Know
- [ ] CRDTs
- [ ] Vector clocks
- [ ] Consistent cutting
- [ ] Change data capture
- [ ] Partition tolerance in practice
- [ ] Metrics, logging, tracing (observability)
