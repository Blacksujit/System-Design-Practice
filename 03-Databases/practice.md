# Databases - Practice Problems

## Problem 1: Design a Social Media Database
**Requirements:**
- Users, posts, comments, likes
- Follow/friend relationships
- News feed generation
- Search functionality

**Schema Considerations:**
- Users table
- Posts table
- Comments table
- Relationships table
- Indexes for common queries

## Problem 2: Design an E-commerce Database
**Requirements:**
- Products, categories, inventory
- Orders, payments, shipping
- User reviews and ratings
- Shopping cart

**Schema Considerations:**
- Product catalog
- Inventory management
- Order processing
- Payment processing

## Problem 3: Design a Real-time Analytics Database
**Requirements:**
- High write throughput
- Time-series data
- Aggregation queries
- Dashboard visualization

**Schema Considerations:**
- Time-series storage (InfluxDB, TimescaleDB)
- Materialized views for aggregations
- Partitioning by time

## Problem 4: Design a Chat Application Database
**Requirements:**
- Messages, conversations
- User presence
- Message history
- File attachments

**Schema Considerations:**
- Messages table
- Conversations table
- User sessions
- File storage (S3)

## Problem 5: Design a Recommendation System Database
**Requirements:**
- User preferences
- Item metadata
- User-item interactions
- Real-time recommendations

**Schema Considerations:**
- User profiles
- Item features
- Interaction logs
- Recommendation cache
