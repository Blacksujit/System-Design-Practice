# Message Queues - Practice Problems

## Problem 1: Design a Notification System
**Requirements:**
- Send push, email, SMS notifications
- Handle millions of users
- Priority notifications
- Retry failed deliveries

**Questions to Ask:**
- What notification types?
- Delivery time requirements?
- How to handle failures?
- What retry strategy?

## Problem 2: Design a Task Queue System
**Requirements:**
- Background job processing
- Task prioritization
- Worker scaling
- Progress tracking

**Questions to Ask:**
- What task types?
- Expected throughput?
- How to handle failures?
- What monitoring needs?

## Problem 3: Design an Event Streaming Platform
**Requirements:**
- Real-time event processing
- Event replay
- Multiple consumers
- High throughput

**Questions to Ask:**
- Event schema?
- Retention policy?
- Consumer groups?
- Partitioning strategy?

## Problem 4: Design a Log Aggregation System
**Requirements:**
- Collect logs from services
- Centralized storage
- Search and analysis
- Real-time streaming

**Questions to Ask:**
- Log volume?
- Retention needs?
- Search requirements?
- Integration points?

## Problem 5: Design a Chat Messaging System
**Requirements:**

**Questions to Ask:**
